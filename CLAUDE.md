# Naksat Saga

Godot 4.7.2 GDScript game (web export, no threads). The owner does not code: explain in plain Thai, keep code comments in Thai.

- Scenes are built in code; `main.tscn` only attaches `main.gd`.
- Art: Gemini pixel-art PNGs in `assets/art/` (single still frame per character, animated in code by `ChibiVisual`/enemy scripts; sprite files are 2x display size). New source images on green/magenta backgrounds go through `python3 tools/prep_art.py <src_dir> assets/art` (keys out the background, builds mirrored tiling backgrounds). Vector `_draw()` art remains as fallback and for platforms, signs and effects.
- Animation: hero forms use frame-by-frame art in `assets/art/frames/hero_<form>_<pose>_<n>.png` (idle, walk x4-6, attack x3, jump, fall, land), cut from Gemini sprite sheets with `python3 tools/prep_frames.py <src_dir> assets/art/frames` (sheets named `naksat_hero_<form>_{walk,attack,poses}.png`; generated in the user's Gemini chat "Chibi Boy Hero Sprite Creation"). Monsters and bosses use frames too (`frog_*`, `mushroom_*`, `tiger_boss_*`, `rat_boss_*`, cut with `tools/prep_monsters.py`, source art faces LEFT). `ChibiVisual` picks frames; `chibi_rig.gd` (cut-out puppet) is only a fallback when a form has no frames; effects live in `entities/effects/fx.gd`; `Game.shake()` / `Game.hit_stop()` for impact. Check poses with `xvfb-run godot --path . res://tests/showcase.tscn -- shots=<dir>`.
- Zodiac outfits (rat, tiger; both genders) are "grand but cute" royal costumes (hood with ears + small gold crown + short cape, full-length pants, chibi big head). They come from ONE combined sheet per form (3 rows: walk x6, idle/land/jump/fall, attack x3, green bg) cut with `python3 tools/prep_grid.py <sheet.png> <hero_rat|heroine_rat|...>`, which also writes the still. Gemini tends to copy the girl's face when asked for the boy: start a NEW chat and paste the boy reference + the girl's costume sheet as images. Gemini often draws monsters facing RIGHT even when asked for left: `prep_monsters.py` has `FLIP_ALL` for those.
- Villages (owner's design): village N has level cap N x 20 (`Game.village`, `Game.level_cap()`, EXP bar stays full at the cap) and 2 zodiacs (Lv.20N-10 and 20N; `Zodiac.village_of()`); village 1 = rat + ox. Tiger (Lv.30) belongs to village 2, not built yet. The left edge of the village (x=70) is the road to the next village, locked until `Game.travel_permit` > `Game.village`.
- Quests: `utilities/quests.gd` (`Quests.LIST`, types kill / collect / zodiac / craft / travel) given in order by the chief (`Game.quest_index`, `quest_accepted`, `quest_progress`, `accept_quest()`, `turn_in_quest()`); turning one in hands out the next. The last quest of a village is the travel permit.
- Crafting: `utilities/crafting.gd` + blacksmith ลุงเหล็ก (village x=1760, `Game.open_crafting()` -> HUD `_craft` window). General recipes roll a quality (ธรรมดา/หายาก/สุดยอด/ตำนาน, item ids `<recipe>__q<1-4>`, stats x1/1.35/1.8/2.5). Zodiacs give one set of parts when beaten (`zpart_<zodiac>_<fang|head|hide|foot|tail>`, `Game.zodiac_gifts`); each part + lots of materials + 500 baht forges a zodiac set piece (`zset_<zodiac>_<slot>`, quality 5). Set pieces are deliberately hard: 30% success, +15% after each failure (`Game.craft_fails`), a failure eats materials and money but keeps the part. Set bonuses at 3 and 5 pieces (`Crafting.SETS[...]["bonus3"/"bonus5"]`, read with `Game.set_effect()`): rat speed / dodge + cooldown, ox HP / damage reduction + no knockback, tiger attack / crit. Item icons: `tools/prep_icons.py <sheet> <names...>`.
- Zodiacs don't have to look like animals: the ox boss is a Thai minotaur warrior (`ox_boss_*`).
- Monsters have levels: `Enemy.KINDS[kind]["lv"]` range; HP +25%, damage +12%, EXP +30% per level above the minimum; `Lv.X` is drawn above each monster (red when higher than the player).
- Critical hits: `Game.BASE_CRIT` 8% (+ tiger set). `Player._damage()` sets `Game.pending_crit`; `Game.hit_enemies()` plays `_crit_fx` (ring, burst, CRITICAL! text, shake, hit stop) and sets `Game.hit_is_crit` so damage numbers are big and orange.
- Mobile / screen: `Hud._on_screen_resized()` switches the canvas to 720x1280 when the window is portrait (1280x720 landscape), moves the hotbar, bag and touch buttons (`TOUCH_LANDSCAPE` / `TOUCH_PORTRAIT`: run sits by the attack button, skill buttons show their name and cooldown, the bottom skill bar hides on touch) and calls `Player.apply_view()` (portrait camera puts the ground at ~62% height; `Stage` fills the area under the road with earth color). The Mali font has no ✕ or ♪: use × and the drawn `SpeakerIcon`. Check layouts with `xvfb-run godot --path . --resolution 720x1560 res://tests/touch_shot.tscn -- shots=<dir>`.
- Title cover `assets/art/title.png` shows both heroes and the 12 zodiacs (มะโรง is a true dragon, id `dragon`); the logo sits under the zodiac arc.
- Boss skill telegraphs use `Fx` kind `warn`: a glowing ground circle that charges up (not a box).
- Other art scripts: `tools/prep_misc.py` (house interior, title cover, equipment icons, rat still). `prep_frames.py`/`prep_monsters.py` take optional names to process only some sheets.
- Backgrounds: village and field use 3 parallax layers (`layer_far.png`, `layer_<style>_mid.png`, `layer_<style>_near.png`, cut with `tools/prep_layers.py`) plus the road strip `ground_<style>.png`; the cave and the chief's house use single `bg_<style>.png` images.
- Systems in `utilities/game.gd`: level/EXP (`add_exp`, +15 max HP and +10% attack per level, capped at `MAX_LEVEL` 150), money, items (`ITEMS`, `REWARDS` drop tables), potions (F), bag (I, in the HUD, tabs equip/item/etc by each item's `tab`; the owner wants no on-screen help or description text), 7-slot item hotbar (`Game.hotbar`, keys 1-7, drag from bag via `HotSlot`/`BagRow` in `ui/hud/hud.gd`). Equipment: items with a `slot` (`EQUIP_SLOTS`: weapon/head/body/feet/charm) are worn via `Game.equip()` / `unequip()` and add `atk` / `hp` / `speed` (`equip_bonus`); the character window (opens with the bag) has the 5 `EquipSlot`s. Drops are `entities/pickups/pickup.gd`. Auntie ป้าศรี runs a shop window (`Game.SHOP` list, HUD `_shop` via `Game.open_shop()`; potions use the item `heal` value, F drinks small then big), Uncle buys `etc` materials that have a `sell` price (`stages/village.gd`).
- Startup flow: title (`ui/title/title_screen.gd`) -> if no profile: `ui/title/character_create.gd` (gender boy/girl, then name, max 12) -> `ui/story/story_cutscene.gd` (5 anime-style panels from `assets/art/story/`, typewriter text, skip) -> play. `Game.in_title` locks input throughout; `main.start_game()` makes a test profile and skips it all in tests. F9 wipes the save and reloads the scene.
- Player profile: `Game.gender` / `Game.player_name` (saved). Girl uses `heroine_*` art: `Game.current_form()` swaps `/hero_` for `/heroine_` in sprite and frame paths, so every hero form needs both `hero_<form>_*` and `heroine_<form>_*` frames (prep with `tools/prep_frames.py <src> assets/art/frames heroine_<form>`, sources `naksat_heroine_<form>_{walk,attack,poses}.png`) plus a still `assets/art/heroine_<form>.png`. Name shows above the player and in the character window.
- Audio: `utilities/sound.gd` (autoload `Sound`, synthesized BGM/SFX with a mute button) was added by another session — keep its hooks when editing.
- Zodiac system (owner's design): the 12 zodiacs are guardians who test the hero every 10 levels in real year order (`utilities/zodiac.gd`: rat Lv.10, ox 20, tiger 30 ... pig 120, god form 150; `ready` marks ones with art). The village gate (x=2050) leads to `stages/chief_house.gd` (chief + quests; the available zodiac's `ZodiacSpirit` appears at the shrine). Talking to it calls `Game.start_trial()`, which sets `Game.active_trial` and sends the player to the zodiac's `arena` (all use `trial_hall`). Bosses are `entities/enemies/zodiac_boss.gd` (`ZodiacBoss.create(id)`, stats from `Zodiac.LIST[...]["boss"]`, or `ZodiacBoss.DEMONS` for non-zodiac demon bosses). The end of the rice field (x=9400) leads to `stages/demon_lair.gd` (Lv.15+): the repeatable demon boss ยักษ์หมอกทมิฬ (`mist_giant`, frames `mist_giant_*`, cut with `tools/prep_monsters.py`); winning unlocks the form with the same id and gives that zodiac's set parts. To add a zodiac: make its hero sheets + boss sheets, add a form in `forms.gd`, set `ready` and `boss` in `zodiac.gd`, add a `REWARDS` entry.
- Add a hero form = one entry in `utilities/forms.gd` (same body size for all forms, outfit only). Skill kinds: melee / dash / aoe.
- Add a map = new script extending `Stage` in `stages/`, registered in `main.gd` STAGES.
- Combat uses rect checks via `Game.hit_enemies()`; enemies are in group `enemies` with `is_alive()`, `get_hurt_rect()`, `take_hit()`.
- Layers: 1 ground, 2 player, 4 enemies, 8 one-way platforms. Ground is y=600.
- Thai text: add spaces at phrase breaks so labels can wrap.
- Verify before pushing: `godot --headless --path . --import && godot --headless --path . res://tests/smoke.tscn` (must print RESULT: PASS). Screenshots: run under `xvfb-run` with `-- shots=<dir>`.
- Pushing to `main` runs `.github/workflows/deploy.yml`, which publishes the web build to the `gh-pages` branch.
