# Naksat Saga (Unity)

Unity 6000.6.7f1 (URP) 2.5D side-scroller, models made in Blender by Python scripts. Targets: web (WebGL, GitHub Pages) and Android. The owner does not code: explain in plain Thai, keep code comments in Thai. The old Godot version was replaced on purpose (owner's choice, history is in git before this rewrite).

- Owner's choices: Unity + Blender, "realistic-ish" look (URP Lit/PBR, soft shadows, ACES tonemapping, bloom), 2.5D side view (walk left/right on z = 0, 3D scenery behind), models built by code in Blender, must run on web and phones.
- Everything is built in code: `Assets/Scripts/Core/GameBoot.cs` runs after the first scene loads, removes the template camera/light and creates `World` (Lighting, Stage, Player, CameraRig, TouchControls). The only scene is `Assets/Scenes/SampleScene.unity`.
- Models: `tools/blender/*.py` (run with the `bpy` pip module: `pip install bpy`, `python3 tools/blender/hero.py -- out.fbx`), exported into `Assets/Resources/Models/<name>` and loaded with `Mats.Model(name, ...)`; when a model is missing the code builds a primitive fallback. Hero joints must be named hips, torso, head, arm_l, arm_r, leg_l, leg_r (`HeroVisual` animates them in code). Preview renders: `python3 tools/blender/preview.py -- model.glb out.png`.
- Player movement is custom (no physics): ground y = 0, one-way platforms in `Stage.platforms` (Rect: x = left, y = top, width), stage width `Stage.width`.
- UI uses UI Toolkit with the Advanced Text Generator (needed for Thai vowels/tones) and the Mali font in `Assets/Resources/Fonts`.
- Input: new Input System only (`activeInputHandler: 1`). Keyboard: arrows/WASD move, Shift run, Space/W jump, J/Z attack, Down+Jump drops through a platform. Touch buttons appear on phones.
- Testing loop: the owner's PC has Unity 6000.6.7f1 and the project at `C:\Users\virgo\NaksatSaga` (computer-use + device file tools). Write files there with device_commit_files, click the editor to recompile, read the Console, press Play. Keep the repo and that folder in sync (repo = source of truth; copy `.meta` files Unity creates back into the repo).
- CI: `.github/workflows/build.yml` (GameCI `unity-builder@v4`, build methods in `Assets/Scripts/Editor/BuildScript.cs`): WebGL -> gh-pages (gzip + decompression fallback because GitHub Pages sends no encoding headers), Android APK -> artifact + release `latest-apk`. Needs secrets UNITY_LICENSE (contents of `C:\ProgramData\Unity\Unity_lic.ulf`), UNITY_EMAIL, UNITY_PASSWORD (the owner enters them; the agent proxy cannot set secrets).
- Game design carried over from the Godot version (to port step by step): villages with level caps (village N cap N x 20, 2 zodiacs each), 12 zodiac trials every 10 levels and zodiac forms, quests from the village chief, crafting with qualities and hard zodiac sets, shop, bag/equipment, demons (ยักษ์หมอกทมิฬ, ผีโป่งค่าง), village 2 บ้านผาจันทร์ with bamboo forest, mobile controls, crits.
