# Naksat Saga — เกม 12 นักษัตร

เกมแอ็กชันเดินตีแนว Maple ธีมไทย ตัวเอกแปลงร่างได้ 14 ร่าง (ร่างปกติ, 12 นักษัตร, ร่างเทพ) แต่ละร่างมี 3 สกิล
สร้างด้วย Godot 4.7 (GDScript)

**เล่นบนเว็บ:** https://mozila023.github.io/naksat-saga/

## ปุ่ม

| ปุ่ม | ทำอะไร |
|---|---|
| ← → | เดิน |
| Shift (กดค้าง) | วิ่งไว |
| Space | กระโดด (↓ + Space = ลงจากแท่น) |
| C | โจมตี |
| A / S / D | สกิล 1 / 2 / 3 |
| Q / E | สลับร่าง |
| ↑ | คุย / เข้าประตู |
| F | ดื่มยาแดง |
| I | เปิด/ปิดกระเป๋า (แท็บ อุปกรณ์สวมใส่ / ไอเทม / ทั่วไป) |
| 1–7 | ใช้ไอเทมในช่อง (ลากไอเทมจากกระเป๋ามาใส่ คลิกขวาเพื่อเอาออก) |
| F9 | ลบเซฟ เริ่มเกมใหม่ |

## สิ่งที่มีตอนนี้

- หน้าปกเกม → เลือกเพศ (ชาย/หญิง) → ตั้งชื่อ → ฉากเล่าเรื่อง → เข้าหมู่บ้าน
- แผนที่: หมู่บ้าน, บ้านผู้ใหญ่บ้าน (หอบูชา 12 นักษัตร), ทุ่งนา (มอนสเตอร์), ลานประลอง, ถ้ำยักษ์หมอกทมิฬ (บอสปิศาจ ตีซ้ำได้ ตั้งแต่ Lv.15)
- หมู่บ้านละ 2 นักษัตร และเลเวลตัน +20 ต่อหมู่บ้าน: หมู่บ้านแรก = ชวด (หนู) Lv.10 + ฉลู (วัว) Lv.20 ตันที่ Lv.20
  - ชนะการประลองแล้วได้ร่างแปลง และชิ้นส่วนนักษัตร 1 ชุด
- เควสจากผู้ใหญ่บ้านหลายเควส (ตีมอน หาของ ประลอง คราฟของ ปราบบอส) เควสสุดท้ายคือใบเบิกทางไปหมู่บ้านถัดไป
- ช่างตีเหล็ก (ลุงเหล็ก): คราฟของสุ่มคุณภาพ ธรรมดา / หายาก / สุดยอด / ตำนาน และตีชุดเซ็ทนักษัตร (ตียาก มีโอกาสพัง) ใส่ครบ 3 / 5 ชิ้นได้ความสามารถพิเศษต่างกันตามนักษัตร
- ร่างละ 3 สกิล, เลเวลสูงสุด 150, เงิน ของดรอป ยาแดง กระเป๋า ช่องไอเทม 1–7 และอุปกรณ์สวมใส่ 5 ช่อง

## โครงสร้างโฟลเดอร์

- `entities/` ตัวละคร มอนสเตอร์ บอส ชาวบ้าน ประตู เอฟเฟกต์
- `stages/` แผนที่ (`stage.gd` คือแม่แบบ แผนที่แต่ละอันเขียนแค่ `build()`)
- `ui/` หน้าจอ HUD
- `utilities/` `game.gd` (สถานะเกม เควส เซฟ) และ `forms.gd` (ข้อมูลร่างและสกิล)
- `tests/` ทดสอบอัตโนมัติ เล่นเควสตั้งแต่ต้นจนจบ

ทุกครั้งที่ push เข้า `main` ระบบจะทดสอบ สร้างเวอร์ชันเว็บ และอัปขึ้นเว็บให้เอง
